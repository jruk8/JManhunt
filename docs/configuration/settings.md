# Settings

**Settings** are a core part in configuring JManhunt. Many default settings are toggled
off to keep the game simple for new users. However, everything included is fully functional
and designed to enhance the experience.

All command examples are the default config settings. Refer to the latest
version of `config.yml` in the [GitHub repository](https://github.com/jruk8/JManhunt/blob/main/src/main/resources/config.yml).

This section is split into focused pages:

- [Match Start & End](settings/match-start-end.md): autostart, the
  pre-start window, head starts, end delay, reminders, and disconnects.
- [Compass Tracking](settings/compass-tracking.md): compass targets,
  who receives one, and tracking distances.
- [Roles](settings/roles.md): roles, friendly fire, lives and respawns,
  debuffs, and invulnerability.
- [Win Conditions & End Screen](settings/win-conditions-end-screen.md):
  what wins a match and which statistics are shown afterwards.
- [Game Boosts](settings/game-boosts.md): world generation and loot odds
  that favor the speedrunners.
